# MTD Explorer

**MTD Explorer** is a bioinformatics pipeline for the integrated analysis
of host transcriptomes and microbial communities from RNA-seq data.

The pipeline combines host transcriptome analysis, microbial taxonomic
classification, functional annotation, differential analysis, and
host–microbiome association analyses in a reproducible workflow.

!!! warning "Development version"

    MTD Explorer is currently under active development. Commands,
    installation requirements, and output structures may change before
    the first stable release.

## Main features

- Integrated host transcriptome and microbiome analysis
- Support for single-end and paired-end RNA-seq data
- Exploratory and group-comparison analysis modes
- Custom host genome support
- Custom host functional annotation
- Microbial taxonomic and functional profiling
- Host–microbiome association analyses
- Online and cache-assisted installation
- Installation verification tools
- Benchmarking utilities
