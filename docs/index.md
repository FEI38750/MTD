  <section class="mtd-section">

    <div class="mtd-section-heading">

      <p class="mtd-section-kicker">
        Integrated analysis
      </p>

      <h2>
        One workflow, multiple biological layers
      </h2>

      <p>
        MTD Explorer was designed to investigate the host transcriptome and
        the biological community represented in the same RNA-seq dataset.
      </p>

    </div>

    <div class="mtd-feature-grid">

      <article class="mtd-feature-card mtd-feature-host">

        <div class="mtd-card-symbol">
          HOST
        </div>

        <h3>
          Host transcriptome
        </h3>

        <p>
          Host-read identification, expression profiling, differential
          analysis, enrichment analysis, and pathway interpretation.
        </p>

      </article>

      <article class="mtd-feature-card mtd-feature-microbiome">

        <div class="mtd-card-symbol">
          MICRO
        </div>

        <h3>
          Microbial community
        </h3>

        <p>
          Taxonomic profiling of bacteria, archaea, viruses, fungi, and
          other organisms represented among non-host reads.
        </p>

      </article>

      <article class="mtd-feature-card mtd-feature-functional">

        <div class="mtd-card-symbol">
          FUNC
        </div>

        <h3>
          Functional activity
        </h3>

        <p>
          Functional annotation and pathway-level interpretation using
          curated reference databases and host-specific annotations.
        </p>

      </article>

      <article class="mtd-feature-card mtd-feature-integrated">

        <div class="mtd-card-symbol">
          LINK
        </div>

        <h3>
          Integrated exploration
        </h3>

        <p>
          Association analyses connecting host expression patterns with
          microbial abundance and functional profiles.
        </p>

      </article>

    </div>

  </section>

      </p>

      <h2>
        Designed for flexible RNA-seq projects
      </h2>

    </div>

    <div class="mtd-feature-grid">

      <article class="mtd-feature-card mtd-feature-host">

        <div class="mtd-card-symbol">
          SE/PE
        </div>

        <h3>
          Single-end and paired-end
        </h3>

        <p>
          A unified workflow for datasets generated with single-end or
          paired-end sequencing strategies.
        </p>

      </article>

      <article class="mtd-feature-card mtd-feature-microbiome">

        <div class="mtd-card-symbol">
          HOST
        </div>

        <h3>
          Custom host support
        </h3>

        <p>
          Use supported reference organisms or prepare custom host genomes
          and functional annotations.
        </p>

      </article>

      <article class="mtd-feature-card mtd-feature-functional">

        <div class="mtd-card-symbol">
          MODE
        </div>

        <h3>
          Multiple analysis modes
        </h3>

        <p>
          Run exploratory analyses, group comparisons, differential tests,
          and host–microbiome association analyses.
        </p>

      </article>

      <article class="mtd-feature-card mtd-feature-integrated">

        <div class="mtd-card-symbol">
          CACHE
        </div>

        <h3>
          Reusable installation cache
        </h3>

        <p>
          Install online or reuse downloaded environments, packages,
          reference genomes, and databases across computers.
        </p>

      </article>
